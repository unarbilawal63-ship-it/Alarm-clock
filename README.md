# Alarm-clock
ChronoPulse is a modern, single-file web alarm clock and productivity suite built with HTML5, Tailwind CSS, and the Web Audio API.✨ Key Features:• 🔔 Custom Alarms with Audio Synthesis• 🕐 Digital &amp; Analog Clock Faces• 🌐 World Time Tracker• ⏱️ Lap Stopwatch &amp; Timer• 🌙 Ambient Sleep Soundscapes• 💾 Auto Local Storage Persistence
